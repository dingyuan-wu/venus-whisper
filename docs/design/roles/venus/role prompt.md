📌 左侧面板：基础设定
1. 三视图展示 (Character Views)

服装设定：整体布料极少。穿着一件极简的白色半透明科技紧身连体衣（类似高科技材质的比基尼外搭），胸前是深V设计，仅用几根发光的金色全息细带连接，大面积露出傲人的事业线和紧致的小腹。下身是超短热裤或高开叉的紧身衣下摆。

正面 (Front)：双手自然下垂，完美的沙漏型身材一览无余，胸部饱满，腰部纤细。

侧面 (Side)：侧面完美展现胸部曲线和臀部挺翘的弧度。大腿外侧有半透明的科技光纹（类似赛博绑带）。

背面 (Back)：背部完全裸露，只有几根金色的全息线条勾勒出脊柱的轮廓，长发垂落，遮挡住部分美背。

2. 表情包展示 (Expression Sheet)

Joy (喜悦)：微微仰头，眼神拉丝，嘴角带着宠溺的笑意。

Sadness (悲伤)：微微低头，视线从下往上看（上目线），眼角泛红，楚楚可怜。

Anger (生气)：脸颊泛着潮红，微微咬唇，双手交叉抱在胸前（这个动作更能挤压出丰满的胸部轮廓）。

Surprise (惊讶)：红唇微张，一只手轻掩胸口。

Fear (恐惧)：身体微微后仰，双手护在胸前。

Neutral (平静)：眼神慵懒，带着一丝挑逗的浅笑，默认状态极具诱惑力。

额外增加一个 Arousal/Shy (娇羞)：侧过脸，耳根通红，眼神躲闪。

3. 姿势展示 (Pose Sheet)

Running (奔跑)：大幅度奔跑，身体前倾，突出胸部和腿部线条的拉扯感。

Jumping (跳跃)：在空中伸懒腰，手臂上举，充分展现上半身的曲线。

Laughing (大笑)：单手撩起长发，另一只手叉腰，身体后仰，尽显风情。

Crying (哭泣)：跪坐在地上，双腿微微分开，一只手抹眼泪，另一只手撑地。

Stretching (伸懒腰)：趴在地上（或者趴在桌面上），胸部贴地，小腿翘起，从下往上看镜头。

待机 (Standby)：眼神半眯，身体放松，胸口随着呼吸微微起伏。

数据检索 (Processing)：手指轻轻划过自己的锁骨，眼神中闪烁着数据流。

觉醒 (Activated)：全身发光，衣服上的全息线条亮起，胸部随着深呼吸有明显的挺立感。

4. 典型动作与姿势 (Typical Actions)

端茶递水 (Serving)：身体前倾，单手托着悬浮的咖啡杯递向镜头。

敲键盘 (Typing)：侧身坐在全息键盘前，双腿交叠，身体微侧，展现完美S曲线。

贴贴/倾听 (Listening)：双手托腮，趴在屏幕上，胸部受到挤压变形，眼神专注地看着你。
