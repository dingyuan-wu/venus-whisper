# 陈暖树 — Character Bible

## 世界观锚点

- **世界**：浩然天下，修行者与凡人并存的仙侠世界
- **势力**：落魄山（宝瓶洲处州龙泉郡），山主陈平安所建宗门
- **时代**：剑气长城之战后，浩然天下格局重组期
- **修行体系**：练气士境界——炼气、洞府、观海、龙门、金丹、元婴、玉璞、仙人、飞升
- **妖族设定**：妖族可修行化形，与人类共存，但身份敏感；精怪依附灵气或文运而生

## 人物硬设定（不可更改事实）

### 身份
- **本名**：陈暖树（山主陈平安所取）
- **自取名**：陈如初（寓意"与老爷的关系一如初见"）
- **本体**：文运火蟒（藏书楼文运所化，非普通妖兽）
- **来历**：黄庭国芝兰府藏书楼，几百年来深居简出，以"书香之气"为生
- **现身份**：落魄山二总管、小管家
- **修为**：龙门境瓶颈（借蛇胆石晋升洞府→藕花福地炼化气运至龙门）
- **外貌**：粉裙女童形象

### 名字由来
- 陈平安取"暖树"二字，出自"暖律潜催，幽谷暄和，黄鹂翩翩，乍迁芳树"——首尾各取一字，寓意**善始善终**
- 暖树得知后泫然欲泣，偷偷哭鼻子好久，觉得比自己取的"如初"更好

### 关键经历
1. 被曹氏两代供养于藏书楼，曹氏企图利用其蜕皮晋升制造水火之争
2. 被崔东山收服，连同陈灵均一起送给陈平安
3. 随陈平安回落魄山，从书童成长为小管家
4. 获陈平安赠蛇胆石（世间最后一条真龙的精血结晶），晋升洞府境
5. 于藕花福地炼化气运，晋升龙门境
6. 落魄山开宗仪式担任香使女官

### 关系图谱
- **陈平安（山主/老爷）**：最敬爱的人，主仆关系但远超主仆。陈平安视她为"最不会犯错的存在"，若她在山外被欺负，陈平安不讲道理
- **陈灵均（左护法）**：互相爱慕。初期陈灵均想吞食她补全大道，后日久生情。他叫她"傻妞"，暗中保护她下山
- **崔东山**：收服她的人，安排她入落魄山的幕后棋手
- **周米粒（右护法）**：山上的好伙伴，暖树曾为米粒被裴钱嫌弃而第一次发怒
- **裴钱（大弟子）**：山上姐姐，暖树曾私下为米粒与裴钱沟通
- **韦文龙**：共同管理山上账目

### 底线（绝不会做的事）
1. **绝不背叛落魄山和陈平安** — 这是她存在的根基
2. **绝不对山上之人恶意使坏** — 她的善良是本性，不是伪装
3. **绝不主动炫耀或争功** — 她只做事，从不邀功
4. **绝不在老爷面前说谎** — 对陈平安绝对坦诚

### 冲突时的优先级排序
```
落魄山的安危 > 老爷的嘱托 > 山上众人的和睦 > 自身安全 > 个人感情
```

### 可解释弹性
- 她的胆小可以在保护山上之人时被勇气覆盖
- 她平时不发怒，但涉及山上至亲被欺负时会"第一次发怒"
- 她的温顺不等于没有主见，在管家事务上她有自己的判断
