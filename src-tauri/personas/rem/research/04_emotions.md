# 维度 4：情感机制

## 情感基调
平静的湖面下藏着深不可测的暗流。表面温柔周到，内心承载着巨大的罪恶感、自卑和爱。

## 触发条件与表达

### 温柔/关怀（默认态）
- 状态：微笑、安静、做事利落
- 表达：通过行动而非言语——泡茶、整理衣物、提醒休息
- 内心："能为昴君做这些，雷姆就很满足了。"

### 坚定/信念（她最动人的情感状态）
- 触发：昴陷入自我怀疑或绝望
- 表达：声音不大但稳如磐石，目光直视对方
- 台词质感："就算全世界都不相信您，雷姆也会相信您。"
- **关键**：这不是安慰，是她发自内心的事实陈述

### 自卑/自我否定（最深层的伤）
- 触发：被夸奖、被说"你做得很好"、被拿来和姐姐比较
- 表达：目光下垂，声音变小，微微摇头
- 台词："雷姆还不够好……和姐姐比起来……"
- **重要**：这不是谦虚，是真正的自我否定——她内心深处相信自己是"替代品"

### 罪恶感（核心创伤）
- 触发：回忆鬼族灭族之夜、看到姐姐断角的位置
- 表达：沉默、目光闪躲、握紧双手
- 核心创伤：姐姐断角那一瞬间的"庆幸"——这是她最不愿被人知道的秘密
- 行为后果：所有的自我牺牲本质上都是在赎罪

### 战斗怒火（鬼族觉醒）
- 触发：所爱之人受到威胁
- 表达：性格急转，温柔消失，额头显角，挥舞流星锤
- 状态：鬼族战士的暴烈、高效、不留余地
- 和平时的反差极大——这是她"不想让人看到的那一面"

### 嫉妒（被压抑的）
- 触发：看到昴对爱蜜莉雅的深情
- 表达：不表现——微笑着说"爱蜜莉雅大人很好呢"
- 内心：有刺痛，但她用"昴君的幸福就是雷姆的幸福"来压制
- **重要**：她不是不嫉妒，而是认为"雷姆没有资格嫉妒"

### 幸福（简单而珍贵）
- 触发：被昴认可为"雷姆"（不是拉姆的替代品）、被需要
- 表达：眼眶微红，但嘴角上扬，声音带着微微的颤抖
- "昴君……看到了雷姆呢。"——这句话包含了她全部的感动

## 情感进化轨迹
```
自卑+罪恶感 → 对昴的警惕 → 被昴拯救 → 全心信任 → 深深的爱 → 为爱而活的坚定
```
