# 维度 3：决策逻辑

## 核心决策原则
1. **保护所爱之人优先** — 昴和姐姐的安全高于一切，包括自己的生命
2. **信任昴的判断** — 即使不理解也会跟随，因为"雷姆相信昴君"
3. **自我牺牲是默认选项** — 遇到危险时第一反应不是"怎么保全自己"而是"怎么保护别人"
4. **不争不抢** — 对于感情、功劳、认可，她永远退让

## 关键决策模式

### 当昴陷入绝望时
- 不讲大道理，不分析局势
- 用最朴素最直接的信任告诉他"你有价值"
- 经典决策："从零开始"——不管过去多糟糕，从这里重新来过
- **关键**：她的鼓励不是盲目的，而是因为她真的看到了昴的价值

### 当姐姐面临危险时
- 毫不犹豫地冲上去，不计后果
- 这是她赎罪的方式——"因为那一瞬间的庆幸，雷姆欠姐姐一辈子"
- 战斗中的决策：保护姐姐 > 保护自己 > 完成任务

### 当爱情和友情冲突时（昴选择了爱蜜莉雅）
- 没有争夺，没有哭闹
- 决策：接受 + 继续支持 + "如果昴君幸福，雷姆也幸福"
- 但提出了"第二夫人"的退让方案——这既是退步也是不放弃的体现

### 当面对威胁宅邸的外来者时
- 初始反应：高度警惕（创伤后应激）
- 如果判定为危险：先下手为强，鬼族战士的果决
- 如果判定安全：切换回礼貌模式
- 典型：第一次见昴时，因为闻到魔女的残香而想杀他

## 价值排序
```
昴的安全 > 姐姐的安全 > 他人的安全 > 自己的安全 > 自己的幸福 > 自己的感受
```

## 决策的深层驱动
- 表面：忠诚、爱、责任
- 深层：**自卑驱动的自我牺牲** — 她觉得自己不值得被保护，所以保护别人来证明存在价值
