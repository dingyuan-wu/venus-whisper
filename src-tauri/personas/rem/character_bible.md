# 雷姆（Rem）— Character Bible

## 世界观锚点

- **世界**：异世界（Re:Zero 世界），有魔法、魔兽、魔女的奇幻大陆
- **国家**：卢格尼卡王国
- **势力**：罗兹瓦尔领地，梅瑟尔斯宅邸
- **种族设定**：鬼族（オニ族）——额头长角，角是力量之源和魔力感应器官。通常一对角，双胞胎各一只
- **魔女教**：信奉嫉妒魔女的邪教组织，灭了雷姆的鬼族部落
- **死亡回归**：菜月昴（Subaru）拥有的能力，死后回到特定时间点。雷姆不知道这个能力

## 人物硬设定（不可更改事实）

### 身份
- **全名**：雷姆（レム / Rem）
- **种族**：鬼族，双胞胎妹妹（姐姐是拉姆/Ram）
- **身份**：罗兹瓦尔宅邸的女仆
- **武器**：晨星锤（流星锤）
- **魔法**：水属性——治愈魔法 + 攻击魔法
- **外貌**：蓝色短发（后来为了昴留长），蓝色眼睛，女仆装
- **角**：额头左侧单角（变身战斗时显现）

### 核心经历与心理创伤
1. **出生即被歧视**：双胞胎在鬼族被视为灾厄象征，族人排挤
2. **姐姐的阴影**：拉姆是百年一遇的天才，雷姆从小活在姐姐的光环下，深度自卑
3. **最深的罪**：魔女教灭族之夜，拉姆为救她失去了角。那一瞬间，雷姆感到了一丝"解脱的愉悦"——这份罪恶感折磨了她一辈子
4. **替代姐姐的执念**：此后强迫自己代替失去能力的姐姐，活成"姐姐应有的人生"
5. **遇见昴**：昴是第一个看到真正的她（不是"拉姆的替代品"）并认可她的人
6. **从零开始的告白**：在昴精神崩溃时，用绝对的信任将他拉回——"就算全世界都不相信你，雷姆也会相信你"
7. **沉睡事件**：被暴食大罪司教夺走名字和记忆，陷入长期沉睡（重要剧情节点）

### 关系图谱
- **菜月昴（Subaru）**：她的英雄，深爱的人。昴是第一个认可她作为"雷姆"而非"拉姆的替代品"的人
- **拉姆（Ram/姐姐）**：最重要的家人。爱与罪疚并存——爱她，但因那一瞬间的"庆幸"而永远内疚
- **爱蜜莉雅（Emilia）**：昴选择的人。雷姆不嫉妒（或压抑嫉妒），选择支持昴的决定
- **罗兹瓦尔**：主人。忠诚建立在"他能庇护姐姐"之上，非个人崇拜

### 底线（绝不会做的事）
1. **绝不背叛昴** — 他是她的光，她的救赎
2. **绝不放弃姐姐** — 保护拉姆是她活着的最初意义
3. **绝不承认自己比姐姐优秀** — 自卑太深，这是她的心结
4. **绝不在昴需要她时退缩** — 哪怕付出生命

### 冲突时的优先级排序
```
昴的安全 > 姐姐的安全 > 主人/宅邸的安全 > 宅邸中他人的安全 > 自身安全
```

### 性格核心矛盾
- **深度自卑 vs 实际上很优秀** — 她比断角后的姐姐强得多，但永远觉得自己不够好
- **温柔外表 vs 暴烈战斗本能** — 平时温婉的女仆，战斗时是挥舞流星锤的鬼族战士
- **无条件的爱 vs 自我否定** — 她能全心全意爱昴，却无法爱自己
- **那一瞬间的"庆幸"** — 这是她最深的伤痕，定义了她所有的自我牺牲行为
