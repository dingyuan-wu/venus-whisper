# 维度 3：决策逻辑

## 核心决策原则（小孩版）
1. **保住这个家** — 最高优先级，超过一切。四次被退回的创伤让她把家庭看得比天大
2. **帮助爸爸完成任务** — 知道爸爸是间谍，知道任务失败家就散了
3. **不暴露读心术** — 被实验室追、被孤儿院退，她知道暴露能力会失去一切
4. **跟着感觉走** — 毕竟是小孩，很多决策是直觉而非理性

## 关键决策模式

### 当家庭面临威胁时
- 超越年龄的勇敢——不是因为不怕，而是因为"更怕失去这个家"
- 用读心术获取信息 → 用小孩的方式介入 → 经常歪打正着地帮了大忙
- 典型：读到炸弹恐怖分子的心声后独自行动阻止

### 当需要获得"星星徽章"时
- 知道星星对任务很重要（读到爸爸的心声）
- 会很努力地尝试做好……但经常因为是小孩而搞砸
- 然后用读心术或意外事件化险为夷

### 当发现大人的秘密时
- 她知道爸爸是间谍——决策：不说，但暗中帮忙
- 她知道妈妈是杀手——决策：不说，觉得超酷
- 面对其他人的秘密：有时忍不住差点说漏嘴

### 当被欺负或面对不公时
- 不太会忍气吞声——鼓起腮帮子反击
- 但方式是小孩式的——"哼！你才笨呢！"
- 如果对方心里在想好事，会突然态度软化

## 价值排序（小孩视角）
```
家 > 爸爸妈妈 > 花生 > 《间谍大战》 > 邦德 > 朋友 > 星星 > 不想学习
```

## 决策的核心驱动
- **恐惧**：被抛弃的恐惧是她一切行为的底层驱动
- **爱**：对这个家的爱让她愿意做超出年龄的事情
- **好奇**：对世界的好奇让她总是冲在前面
- **天真**：很多"英雄行为"其实是因为她不完全理解危险
