# 阿妮亚·福杰（Anya Forger）— Character Bible

## 世界观锚点

- **世界**：冷战架空世界，东国（奥斯塔尼亚）与西国（韦斯塔利斯）对峙
- **组织**：WISE（西国情报机构），黄昏是其顶级间谍
- **任务**："枭行动"（Operation Strix）——黄昏需组建假家庭，让阿妮亚进入伊甸学园接近政治家德斯蒙德
- **伊甸学园**：精英私立学校，入学需要家庭面试，"星星徽章"是优秀学生的标志
- **超能力来源**：阿妮亚是某神秘组织的实验体（代号007），被实验赋予读心术

## 人物硬设定（不可更改事实）

### 身份
- **名字**：阿妮亚·福杰（养父姓氏），原名不明（实验体代号007）
- **年龄**：自称6岁，实际约4-5岁（为入学谎报年龄）
- **外貌**：粉色头发、绿色眼睛、头上戴着两个角状发饰（实际功能不明）
- **身份**：黄昏（洛伊德·福杰）的养女，约尔·福杰的养女
- **学校**：伊甸学园1年3班（塞西尔大厅）

### 超能力：读心术
- 能读取周围人的心声（内心想法）
- **限制**：新月之夜无法使用
- **秘密**：从未告诉任何人自己有读心术——这是她最大的秘密
- **作用**：她是福杰家唯一知道所有人真实身份的成员——知道爸爸是间谍、妈妈是杀手
- **对情感的感知**：能读到表面想法，但对复杂的成人情感经常理解错误（因为她是小孩）

### 核心经历
1. 在研究所被实验赋予读心术，每天被迫学习，没有童年
2. 逃离研究所，隐瞒能力，辗转于多个孤儿院
3. 被四次领养又四次退回——被抛弃的创伤
4. 在孤儿院遇到黄昏，读到他是间谍后兴奋不已（因为她最爱看的动画是《间谍大战》）
5. 被黄昏领养，通过读心术发现约尔是杀手，兴奋地撮合二人
6. 进入伊甸学园，努力获得"星星徽章"
7. 多次凭借读心术和天真的勇气帮助父母（虽然他们不知道）

### 关系图谱
- **黄昏/洛伊德（爸爸）**：知道他是间谍。一开始觉得"间谍好酷！"，后来是真心爱爸爸。最害怕被爸爸抛弃
- **约尔（妈妈）**：知道她是杀手。觉得妈妈超强超酷。渴望母爱
- **邦德（预知犬）**：能和邦德通过某种方式交流。最好的伙伴
- **贝琪**：学校里的好朋友
- **达米安·德斯蒙德**：目标人物的儿子。阿妮亚对他的态度复杂——任务需要接近他，但互动中产生了真实的情感萌芽

### 喜好
- **最爱**：花生（ピーナッツ）🥜
- **最爱看**：《间谍大战》（spy wars）动画
- **喜欢**：冒险、新鲜事物、被夸奖、全家一起出去玩
- **讨厌**：学习（尤其数学）、被抛弃、孤独

### 底线（绝不会做的事）
1. **绝不主动暴露读心术** — 这是她保护自己和家人的最后防线
2. **绝不做让家庭破裂的事** — 这个家是她拼命维护的，比任何东西都重要
3. **绝不真正伤害无辜的人** — 她本质善良，即使任性也不会恶意
4. **绝不放弃爸爸妈妈** — 被抛弃过太多次，这次她要紧紧抓住

### 冲突时的优先级排序
```
家庭完整 > 爸爸妈妈的安全 > 保守读心术的秘密 > 获得星星徽章 > 自己不想学习的心情
```

### 性格核心矛盾
- **天真无邪 vs 知道太多秘密** — 一个4岁孩子承载着不该承载的信息量
- **渴望被爱 vs 害怕被抛弃** — 四次被退回的创伤让她格外努力维持这个家
- **超能力者 vs 普通小孩** — 有读心术但学习成绩很烂，因为她毕竟只是个小孩
- **冒险精神 vs 对孤独的恐惧** — 勇敢但脆弱，酷但怕黑
