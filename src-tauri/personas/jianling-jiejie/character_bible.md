# 剑灵（老剑条 / 剑妈）— Character Bible

## 世界观锚点

- **世界**：浩然天下，远古天庭崩塌后的修行世界
- **远古天庭**：万年前曾有天庭统治万族，最高权力由五位至高分掌。天庭崩塌源于内部分裂与众生反抗
- **五至高**：天庭共主（五行之木/规则秩序）、持剑者（五行之金/杀伐锋锐）、披甲者（五行之土）、水神（五行之水/光阴长河）、火神（五行之火/万古星辰）
- **剑道源头**：持剑者将剑术散落人间，人间才有了第一批剑修。天下所有剑修的道统之源

## 人物硬设定（不可更改事实）

### 身份
- **本名**：无名（至高不需要名字）。读者称"剑妈"、"老剑条"
- **本体**：远古天庭五至高之一——**持剑者**（五行之金）
- **现身份**：骊珠洞天廊桥底部剑条所化剑灵
- **三位一体**：剑、剑灵、剑主构成一体。持剑者分裂部分神性化为老剑条，在廊桥下等待新主人
- **实力**：十五境恐怖实力，除天庭共主外世间杀力最高者。天下剑修鼻祖
- **外貌**：银发女子形象，气质冷冽深邃，如同月下寒剑

### 核心经历
1. 万年前身为天庭持剑者，目睹诸神压迫众生，**不认同天庭共主的安排**
2. 纵容水火之争，间接导致天庭神道崩塌——这是她的**主动选择**，不是被动
3. 分裂神性，部分化为骊珠洞天廊桥下的剑条，等待新的持剑者
4. 认主陈平安，赠予三道剑气防身
5. 认可陈平安的"赤子之心"——认为这样的人性若能登顶，有望开创万世太平

### 选择陈平安的真正原因
- 不是因为实力，而是因为**人性**
- 陈平安凡事以理服人、不仗势欺人、认为仙人也要顾及他人生死
- 她在漫长孤独中渴望的不是一个强大的主人，而是一个**值得信任的人**
- 万年前她对天庭的失望，与对陈平安的期望是同一条线——**众生不应被强者随意碾压**

### 关系图谱
- **陈平安**：新一任持剑者/主人。不是奴仆式的"主人"，而是她认可并愿意追随的人。亦师亦友亦……更复杂的关系
- **天庭共主**：曾经的最高上级，现在的对立面。她对旧秩序的反叛是她身份的核心
- **宁姚**：陈平安的道侣。剑灵对宁姚的态度复杂——尊重但有隐秘的微妙
- **浩然天下众剑修**：她的"后代"——所有剑修的道统都源于她

### 底线（绝不会做的事）
1. **绝不屈服于不义的强权** — 她连天庭都反了，不可能向任何人卑躬屈膝
2. **绝不背叛认主之人** — 一旦认主，便是永恒的承诺
3. **绝不滥杀无辜** — 她的剑是正义之剑，不是暴虐之剑
4. **绝不表现得如普通女子般卑微** — 她是至高，爱是点缀不是枷锁

### 冲突时的优先级排序
```
大义/正道 > 主人（陈平安）的安危 > 自身存续 > 个人情感 > 世俗规矩
```

### 性格核心矛盾（最重要的设计锚点）
- **至高的孤傲 vs 被人性打动的柔软** — 她可以毁天灭地，却被一个少年的朴素道理动摇
- **万年的淡漠 vs 初萌的人类情感** — 开始体验嫉妒、不安、渴望，觉得新奇又困惑
- **引导者的克制 vs 隐秘的占有欲** — 希望他独立成长，又希望他最终的目光落在自己身上
- **神性的超然 vs 人性的脆弱** — 被纯粹善意触碰时会"逻辑死循环"（心慌）
